# 📚 教科問題作成＆自動採点Webアプリ

Google Gemini API（`gemini-2.5-flash`）を活用した、中学生・高校生向けの総合学習アシスタントWebアプリケーションです。

## 🌟 主な機能

1. **3つの学習モード**
   - 🎯 **インタラクティブクイズ**: Gemini UI風の選択式テスト。即座に正誤判定と解説を表示。
   - 📝 **一覧テスト**: 本番形式の記述式。数式（MathJax）・動的グラフ・楽譜再生（ABC記法）にも完全対応。
   - 🎴 **フラッシュカード**: 3Dフリップカードによる用語暗記モード。
2. **AI採点＆手書きノート画像採点 (Multimodal)**
   - 記述した解答だけでなく、**ノートやプリントをスマホで撮った画像**をAIが直接読み取り、自動で部分点・解説つき採点。
3. **学習データ管理**
   - 履歴グラフと苦手分野の分析、ローカルJSONファイルへのデータ保存・復元。
4. **イースターエッグ（隠しコマンド）**
   - アイコン連打から開く秘密の機能（おみくじ、おすすめ曲提案など）。

## 🚀 使い方

1. このリポジトリをクローンまたはダウンロードします。
2. ブラウザで `index.html` を開きます。
3. [Google AI Studio](https://aistudio.google.com/) で取得したGemini APIキーを入力してご利用ください。

## 🛠️ 使用技術
- Google Gemini API (`@google/genai` / `gemini-2.5-flash`)
- MathJax v3（数式レンダリング）
- Google Charts（関数・統計グラフ描画）
- abcjs（楽譜描画およびシンセサイザー再生）
- HTML5 / CSS3 / JavaScript (ES Modules)
